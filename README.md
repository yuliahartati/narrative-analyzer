# Narrative Analyzer

An AI-powered web application that helps users distinguish between facts, claims, opinions, emotional language, missing context, and questions for further verification in articles, social media posts, and opinion pieces.

---

## ✨ Features

- Analyze narrative text with AI
- Distinguish:
  - Facts
  - Claims
  - Opinions
  - Emotional Language
  - Missing Context
  - Questions for Further Verification
- Upload `.txt` and `.md` files
- Copy analysis results
- Download results as Markdown
- Responsive interface
- Dark mode support
